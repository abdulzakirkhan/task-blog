# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

Viva Bot Admin Panel - Client Side

This project is a React + Vite setup using TailwindCSS for styling.

Prerequisites

Node.js version: v24.6.0
Check your version with:

node --version


Environment variables:
Create a .env file in the root folder and define the base URL:

VITE_BASE_URL="https://your-api-url.com/"

Project Setup

Install dependencies:

npm i


Run the development server:

npm run dev


Open in browser:
Vite will provide a local development URL (e.g., http://localhost:5173) after running the dev server.

Features & Tech Stack

React.js – Frontend framework

Vite – Fast build and dev server

TailwindCSS – Utility-first CSS framework

ESLint – Linting rules for cleaner code

React Fast Refresh – HMR for instant feedback

Available Scripts

npm run dev – Start the development server with HMR

npm run build – Build the production bundle
